# Business-Analysis-Case-Study--Digital-Credit-Application-System
Tools: BPA-As-Is-To-Be, MoSCoW, RACI Matrix, User Stories, Gherkin, UAT, RTM, Stakeholder Analysis, Agile/Scrum Backlog Management
●	 Analyzed the manual loan application process and identified duplicate data entry, document rework, sequential controls, and limited SLA visibility.
●	  Modelled the As-Is and To-Be processes using and documented stakeholder needs, business rules, functional and  non-functional requirements, user stories, and Gherkin acceptance criteria.. 
●	  Prioritized requirements using MoSCoW and created a requirements traceability matrix, decision table, risk register, UAT scenarios, and proposed KPIs for the digital loan application process..
